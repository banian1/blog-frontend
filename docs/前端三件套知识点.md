# HTML

## 本项目实际使用的 HTML 标签

### 1. 文档结构标签
| 标签 | 说明 |
|------|------|
| `<!DOCTYPE html>` | 文档类型声明 |
| `<html>` | HTML 文档根元素 |
| `<head>` | 文档头部（元数据） |
| `<body>` | 文档主体内容 |
| `<title>` | 网页标题 |
| `<meta>` | 元数据（字符集、视口等） |
| `<link>` | 外部资源链接（CSS、图标等） |
| `<style>` | 内部样式 |
| `<script>` | 脚本（JavaScript） |

### 2. 文本内容标签
| 标签 | 说明 |
|------|------|
| `<h1> ~ <h6>` | 标题（一级到六级） |
| `<p>` | 段落 |
| `<span>` | 行内文本容器 |
| `<br>` | 换行 |
| `<hr>` | 水平分割线 |

> **Markdown 渲染生成（marked.js）：** `<strong>`、`<em>`、`<code>`、`<pre>`、`<blockquote>`、`<table>` 系列标签会在文章内容渲染时自动生成，无需手动书写。

### 3. 列表标签
| 标签 | 说明 |
|------|------|
| `<ul>` | 无序列表 |
| `<li>` | 列表项 |

### 4. 超链接与多媒体
| 标签 | 说明 |
|------|------|
| `<a>` | 超链接 |
| `<iframe>` | 内嵌网页 |

### 5. 表单标签
| 标签 | 说明 |
|------|------|
| `<form>` | 表单 |
| `<input>` | 输入框（text、file 等） |
| `<textarea>` | 多行文本输入 |
| `<button>` | 按钮 |
| `<label>` | 标签关联 |

### 6. 语义化标签（HTML5）
| 标签 | 说明 |
|------|------|
| `<nav>` | 导航栏 |
| `<footer>` | 页脚 |

### 7. 布局容器
| 标签 | 说明 |
|------|------|
| `<div>` | 块级容器（布局） |

> **属性提示：** 标签通常配合 `class`、`id`、`style`、`src`、`href`、`alt`、`target` 等属性使用。
